# MSDS 451 Term Project

## Machine Learning-Enhanced Adaptive Momentum ETF

This project explores a rule-based momentum investment strategy with machine learning-based risk management.

The proposed portfolio considers SPY, XLF, XLV, IEF, GLD, and SHY. The strategy uses monthly rebalancing, six-month momentum, and a 200-day moving average to select investments. A machine learning model will be developed to estimate downside risk and adjust equity exposure.

The project will compare three approaches: SPY buy-and-hold, a rule-based momentum strategy, and a machine learning-enhanced strategy.
