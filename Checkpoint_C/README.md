# MSDS 451 — Term Project Checkpoint C
## Machine Learning–Enhanced Adaptive Momentum ETF — Performance Evaluation

This checkpoint extends **Checkpoint A/B** and **Programming Assignment 3 (PA3)**. The ETF universe and monthly momentum rule are unchanged. This checkpoint evaluates observed backtest results and additional **Monte Carlo-generated trading paths**. It does **not** train a machine-learning model yet.

## Main trading rule

Five candidates: SPY, XLF, XLV, IEF, GLD. At each completed month-end, identify ETFs with positive **126-day momentum** and price above the **200-day simple moving average**. Buy the highest-ranked two at 50% each. Invest the remainder in **SHY**. Execute at the **next session close**; the next session's return is earned by the old positions. No short positions, derivatives, or leverage.

## Market data and evaluation

- Source: original archived Yahoo Finance daily-history CSVs retrieved on **October 26, 2026** via `yfinance`, carried forward from Checkpoint B.
- Six-asset common price window: **2004-11-18 to 2026-10-26** (5,518 price rows); adjusted closes are **not actual execution prices**.
- Reproduced PA3 historical backtest window: **2005-10-03 to 2026-10-26**. PA3 ending net value **6.371428** from an initial value of 1, checked directly in the notebook.
- Baseline trading costs: **10 basis points** of turnover, with an illustrative **0.25% annual management fee** assessed daily. SPY is the same-window buy-and-hold benchmark.
- Alpha: annualized daily SPY regression intercept (0% risk-free rate); beta: daily covariance divided by SPY variance. These descriptive measures are not a claim of independent alpha or future investment returns.
- Historical stress windows: 2020 COVID sell-off, full 2020, and 2022. Later-period performance from 2016 is reported with hindsight caveats.

## Monte Carlo and validation

- **160** long-horizon synthetic return paths covering the 2016–2026 trading calendar, calibrated on the *pre-2016* historical ETF return vectors.
- **Stationary joint-block bootstrap** with average block length 21 trading days, preserving the contemporaneous six-ETF returns within each sampled day and some local time dependence. Synthetic prices, signals, positions and costs are recomputed for each path; historical post-2015 returns are not inserted into synthetic paths.
- **Expanding-window annual walk-forward:** 24 generated one-year paths for each year 2016–2025 (**240** total) using calibration data only through the previous December.
- Fixed random seeds (`4512026` and `4512027`) and fixed trading rules. No lookback optimization using these outputs.
- Management fee scenarios: 0.25%, 1%, 2%, and 4%; plus illustrative slippage and incentive fees, with limitations documented in the report and notebook.

**Important:** Simulated percentiles and the percentage of synthetic paths outperforming SPY are conditional on the bootstrap assumptions. They are not calibrated forecasts or true probabilities of future returns. The ETF universe was selected as part of a prior retrospective project, so a later chronological evaluation does not erase all selection bias.

## How to run

1. Download the complete repository or its `Checkpoint_C` folder and keep `data/raw/` in the same folder as the notebook. Do not open the notebook from inside a ZIP preview.
2. From the `Checkpoint_C` directory install the packages: `python -m pip install -r requirements.txt`.
3. Open `Checkpoint_C_Performance_Evaluation.ipynb` in Jupyter and choose **Restart Kernel and Run All Cells**. An internet connection is not required.
4. The last cell should print `All Checkpoint C checks passed.` Inspect the CSV tables under `outputs/tables/` and images under `outputs/figures/`.
5. Optional HTML export: `jupyter nbconvert --to html Checkpoint_C_Performance_Evaluation.ipynb`.

The notebook was tested against the PA3 ending net portfolio wealth and under fixed Monte Carlo seeds. Local Python package versions may affect plotting appearance.
